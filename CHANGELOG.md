## [0.1.0] — 2026-10-11

Первая публичная версия: платформа, 22 сценария, установка одной командой.

### Добавлено
- Лицензии: Apache-2.0 для кода, CC BY 4.0 для сценариев и документации.
- `SECURITY.md`, `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, шаблоны issues и pull requests, английские README, установка и правила.
- `wom scenario push`: загрузка сценария на платформу через API, для администратора сборка, регресс, публикация и запуск сессии одной командой. Навык агента `wom-scenario-author` переписан под путь «описал инцидент и инфраструктуру → получил работающий стенд».
- Установка по IP-адресу без домена (самоподписанный сертификат Caddy).
- Поддержка Ubuntu 24.04 LTS в `scripts/provision/*` (репозиторий Docker, профиль AppArmor для rootlesskit).
- Порт базы на хосте выбирается свободный (`DB_HOST_PORT`, по умолчанию 5433), чтобы установка не конфликтовала с другими сервисами на хосте.

### Исправлено
- `deploy.sh` писал логи шагов в фиксированные файлы `/tmp/wom-*.log`: чужой старый файл ломал первый деплой. Логи теперь в `~/.cache/wom-deploy/`.
- `provision.sh`: повторный запуск падал на `git add` из-за игнорируемого `.env`.
- Caddy не отвечал при заходе по IP-адресу (не было `default_sni`).
- `host-setup.sh`: ложное предупреждение о перезапуске Docker при первой установке.
